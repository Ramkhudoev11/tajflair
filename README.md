# TajFlair — Full-Stack E-commerce Website

A full-featured online clothing store with product catalog, shopping cart, checkout, and user authentication.

## Features
- Product catalog with category filters and search
- Product pages with ratings and reviews
- Shopping cart and order checkout
- User registration and login (Django Auth)
- Admin panel for managing products, categories, orders, and reviews

## Tech Stack
Python, Django, PostgreSQL, Django Auth

## Live Demo
https://shop-4cg9.onrender.com
